# Ejecutables de ProtegerDNI

En esta carpeta pueden publicarse los ejecutables compilados:

- `ProtegerDNI_x64.exe` — Windows 10/11 de 64 bits.
- `ProtegerDNI_x86.exe` — Windows 10/11 de 32 bits.

Se recomienda publicar junto a cada ejecutable su archivo SHA-256.

> Los binarios `.exe` deben compilarse en Windows. Los scripts incluidos en `/build`
> y el workflow de GitHub Actions preparan ambas arquitecturas.
