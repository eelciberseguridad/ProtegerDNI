# Por qué proteger los datos de un documento de identidad

Un documento de identidad concentra datos que permiten vincular a una persona con un número identificatorio, una fotografía y otros atributos personales. Cuando se comparte una fotografía completa y reutilizable del documento, se pierde control sobre dónde puede copiarse, almacenarse o volver a utilizarse.

Proteger una copia no significa volverla imposible de robar. El objetivo es reducir el riesgo mediante cuatro principios prácticos:

1. **Minimización de datos.** Compartir únicamente la información necesaria para la finalidad concreta.
2. **Limitación de finalidad.** Individualizar la copia para un destinatario y una fecha determinados.
3. **Reducción de reutilización.** Una marca de agua vinculada al destinatario dificulta utilizar la misma copia fuera de contexto.
4. **Control local.** Evitar subir el documento a servicios innecesarios y no conservar registros adicionales cuando no hacen falta.

ProtegerDNI aplica estos principios permitiendo recortar la fotografía, ocultar manualmente datos que no deban compartirse y generar una copia individualizada. El documento original no se modifica.

La marca de agua y el ocultamiento reducen riesgos, pero no eliminan la posibilidad de que alguien que recibe la copia vea o extraiga los datos que permanecen visibles. La decisión sobre qué datos son necesarios corresponde al usuario y al trámite concreto.
