# Contribuciones

Las contribuciones son bienvenidas siempre que respeten la finalidad gratuita y no
comercial del proyecto.

Antes de abrir un issue o pull request:

- no adjuntar DNI reales ni datos personales;
- usar exclusivamente imágenes de prueba o datos ficticios;
- indicar versión y arquitectura de Windows;
- describir claramente los pasos para reproducir un error;
- conservar la atribución original del proyecto.

Las contribuciones aceptadas se incorporarán bajo la licencia incluida en `LICENSE`.
