# Seguridad y privacidad

ProtegerDNI está diseñado para minimizar la exposición adicional del documento.

- El procesamiento es local.
- No hay telemetría incorporada.
- No se envían documentos a servidores.
- No se crea una base de datos de documentos.
- No se utiliza reconocimiento OCR.
- Los originales no se sobrescriben.

## Reporte de vulnerabilidades

Si detectás un problema de seguridad, evitá publicar documentos de identidad reales o datos personales en un issue público.
